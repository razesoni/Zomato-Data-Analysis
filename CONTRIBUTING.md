# Contributing to Zomato-Data-Analysis

Thanks for your interest in contributing! Please follow these guidelines to make the project easy to maintain and to increase the chances your contribution will be accepted.

1. Fork the repository and create a feature branch from `main` for your changes (feature/my-change).
2. If you're adding code, include tests or a short notebook demonstrating the change.
3. Update `README.md` where appropriate and keep docs clear.
4. Follow existing code style (PEP8 for Python). Use black/flake8 if available.
5. Open a pull request with a clear title and description of what you changed and why.

If your change is large or architectural, open an issue first to discuss the design.
